# Сравнение трёх модифицированных генераторов псевдослучайных чисел с тестированием по критерию хи-квадрат и NIST

Учебный проект по курсу «Методы программирования».  
Реализованы три собственных генератора псевдослучайных чисел:
- **LCG с битовым перемешиванием**
- **Фибоначчи с запаздыванием и переносом (LagFibCarry)**
- **RotMix – на основе циклических сдвигов и XOR**

Проведено тестирование равномерности по критерию χ², выполнены 5 тестов NIST SP800‑22 (частотный, блочный, runs, longest run, серийный), замерено время генерации для объёмов от 1000 до 1 000 000 чисел, построены графики. Сравнение со стандартным генератором `std::mt19937`.

## Сборка и запуск (через Makefile)

Основные цели Makefile:

| Цель            | Действие |
|----------------|----------|
| `make` / `make all` | Полный цикл: генерация выборок, χ², преобразование в биты, NIST-тесты, замер времени, построение графика. |
| `make gen`      | Сгенерировать выборки (20 на генератор) в `generated_data/1,2,3/data.txt` и статистику. |
| `make check_chi2`| Выполнить χ²-тест, записать `chi2.txt` и долю прошедших выборок. |
| `make make_bin` | Преобразовать `data.txt` → `bin_data.txt` (битовые строки). |
| `make nist`     | Запустить пять тестов NIST, записать `nist.txt`. |
| `make fix_time` | Замерить время генерации для всех генераторов (включая `std::mt19937`), сохранить в `time/*/time.txt`. |
| `make plot`     | Построить график времени на основе `time.txt` → `time/time_plot.png`. |
| `make clean`    | Удалить исполняемые файлы, все сгенерированные `.txt` и `.png`. |
| `make rebuild`  | `make clean all` (полная перегенерация). |
| `make dox`      | Сгенерировать документацию Doxygen в `docs/html/` и открыть её. |
| `make clang`    | Отформатировать `.cpp` и `.hpp` в стиле Google (требуется `clang-format`). |

## Описание генераторов
### Генератор 1: LCG с битовым перемешиванием

- Классический LCG с параметрами `a = 1664525`, `c = 1013904223`, `m = 2³²`.
- Дополнительное перемешивание:  
  `out ^= out >> 16; out ^= out << 13; out ^= out >> 5;`

### Генератор 2: Фибоначчи с запаздыванием и переносом (LagFibCarry)

- Лаги 17 и 5, комбинированная операция `(a + b) ^ (a >> 3) + carry`.
- Перенос обновляется: `((a + b) >> 28) ^ (new_val >> 28) & 0xF`.
- Дополнительное перемешивание XOR со сдвигами.

### Генератор 3: RotMix

- Три состояния, обновляемые через циклические сдвиги и XOR.
- Выходное значение умножается на константу `0x85EBCA77` (переполнение 32 бит).

### Генератор 4: std::mt19937

- Стандартный генератор C++ (вихрь Мерсенна). Используется как эталон скорости и качества.

## Формат выходных данных

- `generated_data/<gen>/data.txt` – 20 строк, каждая содержит 32-битные целые числа через пробел.
- `generated_data/<gen>/stats.txt` – таблица: номер выборки, размер, среднее, стандартное отклонение, коэффициент вариации.
- `generated_data/<gen>/chi2.txt` – номер выборки, значение χ², `1`/`0` (прошёл/не прошёл).
- `generated_data/<gen>/bin_data.txt` – битовые строки (по 32 бита на число, 1000×32 бит на выборку).
- `generated_data/<gen>/nist.txt` – P‑values для пяти тестов NIST.
- `time/<gen>/time.txt` – строки вида: `<размер> <время_в_секундах>`.
- `time/time_plot.png` – итоговый график сравнения скоростей.

## Интерпретация результатов (кратко)

### Равномерность по χ² (16 интервалов, ν = 15, α = 0.05)

| Генератор | Проход χ² | Оценка |
|-----------|-----------|--------|
| 1 (LCG)   | 17/20     | Хорошая равномерность (3 отказа) |
| 2 (LagFib)| 19/20     | Отличная равномерность (1 отказ) |
| 3 (RotMix)| 0/20      | Неравномерен (χ² >> 27.488) |

### Пять тестов NIST (α = 0.01)

| Генератор | Отказы | Комментарий |
|-----------|--------|-------------|
| 1 (LCG)   | Frequency: выборка 14 (P=0.00729)<br>Serial: выборка 10 (P=0.00391) | Два отказа – допустимо |
| 2 (LagFib)| Serial: выборки 3 (P=0.00698), 17 (P=0.00831) | Два отказа – приемлемо |
| 3 (RotMix)| все P‑value практически нулевые | Полный провал |

### Скорость генерации (время на 1 млн чисел, секунды)

| Генератор | Время (сек) |
|-----------|-------------|
| LCG (ген.1) | 0.00860 |
| LagFibCarry (ген.2) | 0.01596 |
| RotMix (ген.3) | 0.01097 |
| mt19937 | ~0.0112 (из предыдущих замеров) |

**Вывод:** LCG и LagFibCarry пригодны к использованию (LCG незначительно быстрее, LagFibCarry даёт более равномерное распределение). RotMix не удовлетворяет ни одному тесту, его применение недопустимо.
